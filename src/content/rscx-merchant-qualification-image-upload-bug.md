# 商户资质图片上传问题技术复盘

## 1. 问题现象

在商户入驻申请页（`pages/rscx/merchant/apply`）开发图片上传功能时，共暴露四个相互关联的问题：

**问题一：上传成功后图片预览显示空白。** 调用后端 `/infra/file/upload` 接口返回成功，资质文件 URL 已写入表单数据，但页面预览区为灰色占位背景，不显示图片。

**问题二：上传后文件名显示为微信临时文件 hash。** 预览区底部文件名标签展示的是 `tmp_4a7b9c.png` 形式的随机字符串，而非用户可辨识的资质类型名称（如"营业执照"）。

## 2. 影响范围

- 商户入驻资质上传页面的所有图片附件上传项（营业执照、法人身份证等）。
- 仅影响 UI 体验和文件管理的规范性，不影响核心入驻流程。

## 3. 根因链路

```text
文件选择 → uni.chooseImage() 获取 tempFilePath
        ↓
文件上传 → uni.uploadFile()
        ↓
后端返回存储服务 (S3/OSS) 原始地址（如 s3://bucket/xxx.png）
        ↓
前端直接绑定原始地址到 <image> 标签的 src
        ↓
浏览器/微信由于安全限制或缺少内网穿透无法加载 s3:// 协议地址
        ↓
图片预览显示空白
```

## 4. 修复方案

**策略一：使用 Nginx 代理或 CDN 地址作为预览 URL**
后端返回的文件地址必须是公网可访问的 HTTP/HTTPS 地址。如果后端返回的是内部存储协议地址，前端需要通过全局配置（`baseUrl`）进行拼接或转换。

**策略二：手动重命名上传文件**
在调用 `uni.uploadFile()` 之前，先根据业务上下文设置 `name` 属性，确保文件在存储桶中具有描述性。

## 6. 后续防护

- 统一封装上传组件，内置 URL 协议转换逻辑。
- 增加上传前的图片大小和格式压缩逻辑，优化用户体验。
