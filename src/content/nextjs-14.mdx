# Next.js 14 入门指南

Next.js 14 已经发布，它比以往任何时候都更好。这次的重点是稳定性和性能，特别是全新的 **App Router**。

## 核心特性

1. **Server Actions**：无需编写 API 路由即可修改数据。
2. **局部预渲染 (Partial Pre-rendering)**：兼具静态和动态的优势。
3. **改进的 Metadata API**：更好的 SEO 管理。
