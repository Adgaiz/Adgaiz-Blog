# 现代网页排版设计

排版不仅仅是关于字体。它关乎间距、对比度和层次结构。

## 最佳实践

- **限制字体族**：使用 1 或 2 个字体系列。
- **行高**：正文文本的目标行高为 1.5 到 1.6。
- **对比度**：确保文本与背景之间有足够的对比度，以便阅读。

请记住：*设计是为用户服务的。*
