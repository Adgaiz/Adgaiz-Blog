# MDX 的强大功能

MDX 将 Markdown 的简洁与 React 的功能结合在一起。

## 为什么要使用 MDX？

- **交互式组件**：嵌入图表、地图或交互式演示。
- **动态内容**：在文章内部使用 Props 和 State。
- **现代工作流**：完美契合 Next.js。

你甚至可以直接导入组件：

`import { Chart } from './components/Chart'`
