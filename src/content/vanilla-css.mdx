# 为什么原生 CSS 依然强大

原生 CSS 已经发生了巨大的进化。凭借 CSS 变量、Grid 和 Flexbox 等特性，我们可以用极小的代价构建复杂的布局。

## 原生 CSS 的优势

- **零运行时**：无需额外的 JS 解析。
- **可移植性**：随处可用。
- **完全掌控**：没有隐藏的黑盒逻辑。

### CSS Modules

We use CSS Modules to prevent global namespace pollution.

```css
.card {
  padding: 1rem;
  border-radius: 8px;
}
```

It's simple and effective.
