# 深入理解服务端组件

服务端组件允许您在服务器上运行代码，从而减少发送到客户端的 JavaScript 量。

## 核心优势

- **更小的包体积**：依赖项保留在服务器上。
- **直接访问数据**：直接从组件中查询数据库。
- **更好的性能**：更快的初始页面加载。

它是 React 生态系统的重大变革。
